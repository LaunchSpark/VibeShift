# Project skills

Claude Code loads every folder here as a skill for anyone working in this repo,
so the whole team gets the same marimo guidance when editing notebooks like
`notebooks/emotion_tracker.py` and `evaluation/eval/explore_eval.py`.

| Skill | Use it for | Upstream |
| --- | --- | --- |
| `marimo-notebook` | Writing marimo notebooks correctly (cells, reactivity, UI) | marimo-team/skills |
| `marimo-pair` | Driving a live marimo kernel alongside you | marimo-team/marimo-pair |
| `marimo-batch` | Preparing a notebook for scheduled/batch runs | marimo-team/skills |
| `anywidget-generator` | Custom interactive widgets for notebooks | marimo-team/skills |
| `jupyter-to-marimo` | Converting `.ipynb` to marimo | marimo-team/skills |
| `streamlit-to-marimo` | Converting a Streamlit app to marimo | marimo-team/skills |
| `wasm-compatibility` | Checking a notebook can run in the browser (WASM) | marimo-team/skills |
| `add-molab-badge` | "Open in molab" badges for notebooks | marimo-team/skills |

These are vendored copies of the public skills at
[marimo-team/skills](https://github.com/marimo-team/skills) and
[marimo-team/marimo-pair](https://github.com/marimo-team/marimo-pair), both
Apache-2.0 (license text in [`LICENSE-marimo-skills`](LICENSE-marimo-skills)).
Copied 2026-10-29, unmodified. To refresh one, re-copy its folder from upstream.
